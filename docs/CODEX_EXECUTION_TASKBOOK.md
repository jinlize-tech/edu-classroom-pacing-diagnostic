## 2. 用户、痛点与目标

- 用户：教师、教研主管、课堂督导、新教师带教人
- 痛点：新教师讲得多、练得少，或课堂前松后紧；现有反馈往往只说“节奏需要优化”，没有可核对证据。
- 目标：根据课堂时间轴和活动记录诊断讲授、练习、互动、过渡和管理时间的结构，定位卡点并给出下一次实验。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `classroom_timeline` | 课堂时间轴 | array | 是 |
| `lesson_objectives` | 课堂目标 | array | 是 |
| `lesson_duration` | 课堂时长 | integer | 是 |
| `age_group` | 学生年龄或年级 | string | 是 |
| `teacher_self_review` | 教师自评 | string | 否 |

## 4. 工作流

1. 核对时间记录
2. 标注活动类型
3. 统计占比和切换
4. 对照目标
5. 识别过久/过短环节
6. 提供一个可测试的节奏调整

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点课堂时间轴、活动记录或转录、教学目标、学生年龄、课堂长度、观察重点、教师自评，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕根据课堂时间轴和活动记录诊断讲授、练习、互动、过渡和管理时间的结构，定位卡点并给出下一次实验。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按核对时间记录 → 标注活动类型 → 统计占比和切换 → 对照目标 → 识别过久/过短环节 → 提供一个可测试的节奏调整设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `时间分布图文本`
- `活动序列`
- `目标保障风险`

## 7. 差异化与排重

- 与现有产品：课堂观察量表生成评价工具；本产品分析一节课的节奏数据，不承担完整教师评价。
- 排重检查：有限重叠；本产品只做节奏与时间结构，不输出综合教师能力或成长计划。
- 独立理由：仅输入时间轴或课堂记录即可独立使用。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
