# 课堂节奏与时间分配诊断领域指南

## 业务问题

新教师讲得多、练得少，或课堂前松后紧；现有反馈往往只说“节奏需要优化”，没有可核对证据。

## 产品解决方案

根据课堂时间轴和活动记录诊断讲授、练习、互动、过渡和管理时间的结构，定位卡点并给出下一次实验。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `classroom_timeline` | 课堂时间轴 | 是 | 活动、起止时间与观察记录 |
| `lesson_objectives` | 课堂目标 | 是 | 关键目标与优先级 |
| `lesson_duration` | 课堂时长 | 是 | 分钟 |
| `age_group` | 学生年龄或年级 | 是 | 用于节奏基准 |
| `teacher_self_review` | 教师自评 | 否 | 教师对本节课节奏的判断 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

时间记录需准确；不能仅凭比例认定教学质量；不同课型需要人工调整基线。
